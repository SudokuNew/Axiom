# Axiom（アクシオム）

中学数学の基礎計算を、毎日ひたすら解いて速くする練習アプリです。
ビルド作業なし。HTML / CSS / JavaScript だけで動きます。iPhone ではホーム画面に追加するとアプリとして使えます。

## できること（v0.1 骨組み）

- ボタン1つで「今日の演習」開始（初期設定は1日100問。50 / 100 / 150 / 200 / 300問から選べる）
- 解く → まちがえたら、その場で正解するまで次へ進めない（2回まちがえると答えが出る） → 最後に自動で集計（一発で正解できた数）と、まちがえた問題の見直し
- 単元ごとに専用テンキー（二次方程式は √ ± , ( ) / 付き、分数は / と − だけ）
- 週ごとにレベルアップ：1週目 基礎 → 2週目 工夫 → 3週目以降 入試レベル（設定で固定も可）
- 連続日数・正答率・かかった時間の記録（端末内に保存）、途中で中断してもつづきから再開
- オフライン対応、Windows ではキーボードでも解答可（数字・Enter・Backspace・`-`・`,`・`/`・`r`=√・`p`=±）

入っている単元：**二次方程式**、**分数の計算**（見本）。範囲が決まったら追加していきます。

## 公開のしかた（GitHub Pages・無料・約10分）

1. GitHub にログインし、右上の「＋」→ **New repository**。名前を `axiom` にして **Public** で作成。
2. 作成した画面の **uploading an existing file** を押し、このフォルダの**中身すべて**（`index.html`、`js` フォルダ、`icons` フォルダ など。`tests` は不要）をドラッグして **Commit changes**。
   - フォルダごとドラッグできない場合は、zip を解凍してから中身を選んでドラッグしてください。
3. **自動公開の設定ファイルを作る**（ドラッグでは `.github` フォルダが入らないため、画面上で作ります）。
   リポジトリの **Add file → Create new file** を押し、ファイル名の欄に `.github/workflows/pages.yml` と入力します（`/` を打つとフォルダになります）。中身はこのフォルダの `.github/workflows/pages.yml` をそのまま貼り付けて **Commit changes**。
4. リポジトリの **Settings → Pages** を開き、**Source** を **GitHub Actions** にする（Branch ではありません）。
5. **Actions** タブで「Deploy Axiom」が緑のチェックになるまで待つ（1〜2分）。失敗していたら、赤い × を開くとテストのどこが悪いか読めます。
   手順3・4の順番が逆で動かなかったときは、Actions タブ → Deploy Axiom → **Run workflow** で再実行できます。
6. Settings → Pages の上部に `https://（あなたのユーザー名）.github.io/axiom/` と表示されます。これがアプリの URL です。

### iPhone（17e）でアプリにする
1. **Safari** で上の URL を開く（Chrome ではなく Safari）。
2. 共有ボタン → **ホーム画面に追加** → 追加。
3. ホーム画面の「Axiom」から全画面で起動できます。

### Windows PC
ブラウザで同じ URL を開くだけです。Edge / Chrome ならアドレスバーの「インストール」でアプリ化もできます。

## 更新のしかた（改良したとき）

1. ファイルを直す（GitHub 上で鉛筆アイコン、またはリポジトリで `.` キーを押して出る Web エディタ）。
2. Commit する。**自動でテストが走り、通ったら1〜2分で公開されます**（テストに失敗したときは公開されず、前の版のまま）。
3. 反映されないときは、アプリの設定画面の「最新版に更新」を押す。

`sw.js` の `VERSION` は、公開のたびに自動で新しい値に置き換わるので、手で上げる必要はありません。

## 手元で動作確認したいとき

```
python3 -m http.server 8000     # → ブラウザで http://localhost:8000
node tests/test.js              # 問題生成・採点の自動テスト（全部「成功」なら正常）
```

## 注意

- 無料の GitHub Pages ではリポジトリが公開になります。個人情報は入れないでください。記録は各自の端末内だけに保存され、サーバーには送られません。
- iPhone の記録は、Safari で長期間（数週間）まったく開かないと消えることがあります。ホーム画面から毎日使えば問題ありません。念のため設定の「書き出し」で時々バックアップを。
- 入試レベルの問題は、出題傾向に合わせたオリジナル問題です（過去問は載せていません）。

AI に改良を頼むときは、`AI_GUIDE.md` を一緒に渡してください。
